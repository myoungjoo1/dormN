# DormN 🏠

**DormN**은 기숙사 거주 학생들을 위한 공동구매 및 N빵 플랫폼입니다.

대용량 생필품이나 배달음식처럼 혼자 구매하기 애매한 상품을  
같은 기숙사에 사는 사람들과 함께 나누어 구매하고,  
모집부터 정산, 픽업까지 한 번에 관리할 수 있도록 합니다.

---

## DormN은 이렇게 사용합니다

예를 들어 기숙사에서 햇반 24개를 사고 싶은데  
혼자 24개를 전부 구매하기에는 부담스럽다고 가정합니다.

DormN에서 공동구매 글을 작성합니다.

```text
햇반 24개

총 가격 : 22,900원
내가 가져갈 수량 : 4개
모집 수량 : 나머지 20개
모집 마감 : 오늘 20:00
픽업 장소 : 수경재 1층
```

같은 기숙사에 거주하는 다른 사용자는  
DormN에서 해당 공동구매를 발견하고 원하는 수량만큼 참여할 수 있습니다.

```text
717-1 → 4개
709-2 → 6개
615-1 → 2개
...
```

모집이 끝나면 DormN이 각 참여자의 수량에 따라  
내야 할 금액을 자동으로 계산합니다.

```text
내 수량
4개

내가 보낼 금액
3,817원
```

참여자는 모집자에게 직접 송금하고  
DormN에서 송금 여부를 확인할 수 있습니다.

상품이 도착하면 기숙사 내부에서 상품을 나누어 받은 뒤  
각 사용자가 수령 완료를 표시합니다.

모든 참여자가 상품을 받으면 공동구매가 완료됩니다.

---

## 전체 이용 흐름

```text
공동구매 글 작성
        ↓
기숙사 사용자 모집
        ↓
원하는 수량만큼 참여
        ↓
모집 마감
        ↓
개인별 금액 자동 계산
        ↓
모집자에게 송금
        ↓
상품 주문
        ↓
기숙사 도착
        ↓
상품 픽업
        ↓
수령 완료
```

---

## 기숙사 거주자 인증

DormN은 같은 기숙사에 거주하는 사람들끼리  
안전하게 공동구매할 수 있도록 기숙사 거주 여부를 확인합니다.

사용자는 카카오 계정으로 로그인한 뒤  
기숙사 위치 확인과 관생증 인증을 거쳐 DormN의 거래 기능을 사용할 수 있습니다.

서비스 내에서는 실명 대신

```text
717-1
717-2
709-1
```

처럼 **호실 기반 이름**을 사용합니다.

이를 통해 불필요하게 실명을 공개하지 않으면서도  
같은 기숙사 구성원이라는 최소한의 신뢰를 유지하는 것을 목표로 합니다.

---

## DormN이 해결하고 싶은 것

기숙사에서 공동구매를 할 때는 보통

```text
사람 모집
→ 수량 확인
→ 금액 계산
→ 계좌번호 공유
→ 입금 확인
→ 배송 공지
→ 픽업 관리
```

를 모두 채팅방에서 직접 처리해야 합니다.

DormN은 이 과정을 하나의 서비스 안에서 관리하여

> **기숙사에서 필요한 것을 더 쉽게 같이 사고, 더 간단하게 나누는 것**

을 목표로 합니다.
